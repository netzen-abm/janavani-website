## 1. Purpose

This document is the permanent register of reference material used to develop the Janavani website.

Its purpose is to ensure that important content decisions, source material, terminology, claims, and distinctions do not exist only in conversation.

Future website upgrades must consult this register before creating or substantially changing public content.

---

# 2. Core Rule

A reference document is not automatically a statement of current Janavani capability.

Every reference must be classified before its content is reused.

The following distinction must always be maintained:

```text
CURRENT
Implemented and verified in the repository
        ↓
BUILDING
Actively being developed
        ↓
FUTURE / RESEARCH
Strategic or exploratory direction
        ↓
REFERENCE ONLY
Useful source material but not an approved Janavani claim
        ↓
HISTORICAL / SUPERSEDED
Kept for project history, not current authority
