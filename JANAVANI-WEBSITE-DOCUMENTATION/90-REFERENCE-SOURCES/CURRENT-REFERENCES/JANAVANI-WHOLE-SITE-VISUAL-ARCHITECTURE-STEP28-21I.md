## STEP 28-21I — DESIGN ARCHITECTURE LOCK

Status: DESIGN FOUNDATION
Date: 2026-08-19

---

# 1. CORE DESIGN IDEA

Janavani must feel like:

A civic platform built by citizens,
for citizens,
with constitutional dignity,
clarity,
participation,
accountability,
and future possibility.

The website must not feel like:

- a corporate SaaS website
- a government department website
- a political campaign website
- a news portal
- a collection of information cards
- an advertisement

The desired experience is:

CITIZEN
↓
UNDERSTAND
↓
RECOGNISE
↓
ACT
↓
PARTICIPATE
↓
FOLLOW THROUGH
↓
BUILD TRUST
↓
SHAPE THE FUTURE

---

# 2. CONSTITUTIONAL ENTRY

The Home page MUST begin with:

WE, THE PEOPLE OF INDIA

This is the constitutional and emotional entry point.

The Home page must then establish:

SOVEREIGN
SOCIALIST
SECULAR
DEMOCRATIC
REPUBLIC

The constitutional opening must feel:

- dignified
- spacious
- confident
- modern
- citizen-centred

It must NOT feel:

- theatrical
- political propaganda
- overcrowded
- decorative

The Preamble image is NOT used on Home.

Every page should follow a deliberate hierarchy.

LEVEL 1

LEVEL 2

LEVEL 3

LEVEL 4
What the citizen can do

LEVEL 5
What exists now

LEVEL 6
What Janavani is building

LEVEL 7
Future possibility

LEVEL 8
Call to participation

---

# 4. REDUCE CARD DEPENDENCY

Current audit:

162 card/panel signals across the website.

This is too high.

Cards should only be used when they communicate:

- comparison
- choice
- distinct action
- distinct concept
- structured information

Cards must NOT be used merely because:

"the content needs a box."

Prefer:

- open layouts
- editorial sections
- numbered pathways
- horizontal relationships
- timelines
- process diagrams
- visual anchors
- whitespace
- typography hierarchy

---

# 5. VISUAL STORYTELLING PRINCIPLE

MASTER RULE:

VISUALS MUST EXPLAIN SYSTEMS,
NOT MERELY DECORATE.

Use:

DIAGRAMS
for relationships.

PROCESS FLOWS
for sequences.

TIMELINES
for development.

INFOGRAPHICS
for structured concepts.

ILLUSTRATIONS
for abstract ideas.

PHOTOGRAPHY
only where human context adds meaning.

CHARTS
ONLY where legitimate data exists.

Never invent statistics for visual impact.

# 13. NOW / BUILDING / FUTURE

This distinction must remain visible and honest.

NOW:

What exists and works today.

BUILDING:

What is actively being developed.

FUTURE:

What Janavani could become.

Never present future concepts as existing functionality.

---

# 14. TYPOGRAPHY

Typography must carry hierarchy.

Priority:

1. Constitutional statement
2. Page title
3. Section title
4. Section explanation
5. Action
6. Supporting detail

Avoid excessive heading levels.

H3 should not be used simply because another visual box needs a heading.

---

# 15. SPACING

Use whitespace deliberately.

The website should breathe.

Avoid:

- dense card stacking
- excessive borders
- excessive shadows
- visual noise
- repeated identical section structures

---

# 16. COLOUR

Preserve the existing Janavani colour system where useful.

The visual language should communicate:

- constitutional dignity
- civic trust
- clarity
- seriousness
- participation
- future possibility

Do not introduce a large number of unrelated colours.

---

# 17. INTERACTION

Interactions should clarify.

Use:

- hover states
- focus states
- subtle transitions
- progressive disclosure where useful

Avoid:

- unnecessary animation
- decorative motion
- distracting effects

Respect reduced-motion preferences.

---

# 18. ACCESSIBILITY

Maintain:

- semantic HTML
- meaningful alt text
- keyboard focus
- readable contrast
- logical heading hierarchy
- accessible SVG treatment
- reduced-motion support

Images should receive width/height dimensions where appropriate to reduce layout shift.

---

# 19. RESPONSIVE DESIGN

The experience must remain coherent across:

DESKTOP
TABLET
MOBILE

Mobile is not a compressed desktop.

The civic narrative must remain intact.

---

# 20. DESIGN TEST

Every redesigned section must answer:

1. What is this section saying?

2. Why does the citizen need to know it?

3. What should the citizen understand after seeing it?

4. Is a visual actually useful?

5. Does the visual explain something?

6. Can this section be simpler?

7. Does this move the citizen toward participation?

If not:

REMOVE
SIMPLIFY
OR RESTRUCTURE.

---

# 21. WOW STANDARD

The final Janavani experience should create this reaction:

"I immediately understand what this is."

Then:

"This is different."

Then:

"I can see how it works."

Then:

"I can actually participate."

And finally:

"This could become a new layer of citizen infrastructure."
